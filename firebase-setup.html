Required Firebase Console settings
  1. Open Firebase Console → Authentication → Get started.
  2. Open Sign-in method.
  3. Enable Email/Password.
  4. Save.
  5. Open Authentication → Settings → Authorized domains and make sure the domain you are using is listed. For local development, add localhost if needed.
